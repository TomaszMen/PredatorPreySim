Praca inżynierska

Projekt ma być symulatorem środowiska w którym drapieżniki i ofiary walczą o przeżycie

Wykorzystywane jest QT Createor, projekt stworzona jako Aplikacja QT Widgets

Program aktualnie ma zbudowane podstawowe SI drapieżników i ofiar
Uciekanie, jedzenie, gonienie itd.
Aktualnie pracuje nad "czasem spoczynku"
Następnie rozróżnię młode zwierzęta od starszych i zaimplementuję SI stadne

HARMONOGRAM
1. praca na parametrach tak aby środowisko nigdy nie skończyło puste - aby cykl trwał w nieskończoność
2. dodanie wykresów pozwalających obserwacje statystyk zwierząt
3. dodanie funkcji pozwalających na manipulację środowiskiem
4. oddanie projektu
